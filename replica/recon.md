## 범위
- 앱: Mirr (웹), 슬라이스: "소재 찾기 → 만들기 → 올리기 → 댓글/DM → 성과" 한 바퀴

## 핵심 루프
소재(기획) 추천 → 형식별 제작(카드뉴스/영상/블로그/Threads·X 글) → 예약 발행 → 댓글 모아보기·자동 DM → 콘텐츠별 성과 비교 → 다음 소재
+ 위를 "콘텐츠 자동화"(문장으로 지시 → 계획·샘플 확인 → 일정 반복)로 묶음.

## 플랜으로 본 중요도 (요금표)
전 플랜 공통: 기획·카드뉴스·블로그·영상·예약발행·성과·댓글/AI답글·댓글 DM 자동화·MCP.
한도로 파는 것: AI 크레딧, SNS 계정 수, **콘텐츠 자동화 개수**, 링크 페이지 수, 사용자 수. → 자동화와 크레딧이 과금 핵심.
